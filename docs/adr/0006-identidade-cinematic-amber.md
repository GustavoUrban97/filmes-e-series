# 0006. Claquete, com a identidade Cinematic Amber

- **Situação:** aceita
- **Data:** 2026-11-06

## Contexto

Foram criadas telas de referência para o produto, com o nome Claquete e o design system Cinematic Amber. O site deveria ficar o mais próximo possível delas.

## Decisão

Adotar o nome e a identidade, reconstruindo as telas com dados reais. Elementos de exemplo sem fonte de dados ficaram de fora.

## Alternativas

- **Manter a Sala escura:** descartada pelas novas telas.

## Consequências

- O site passa a ter grade de pôsteres, página de título, Diário e Estatísticas.
- Nem tudo é igual às telas, como consenso crítico e classificação indicativa.
- As regras ficam em [Identidade visual](../referencia/identidade-visual.md).
